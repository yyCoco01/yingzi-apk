# 影子 · 安卓体验版

影子可以把一个短片想法变成分镜，按镜头拍摄或导入素材，再把成片导出到相册。这里发布适用于 Android 10 及以上手机的体验版安装包与更新说明。

## 在手机安装

用手机浏览器打开下方的下载链接，下载完成后点开 `yingzi.apk`，按安卓系统提示安装。已经装过旧体验版的用户可以直接覆盖安装，保留本机草稿。

[下载最新版 APK](https://github.com/yyCoco01/yingzi-apk/releases/latest/download/yingzi.apk) · [查看各版更新说明](https://github.com/yyCoco01/yingzi-apk/releases)

## 后续更新

从 0.3.1 起，打开影子时会定期检查新版，也可以在「我的 → 检查更新」里立即检查。发现新版后点「立即更新」，影子会显示下载进度。首次使用时按提示允许影子安装更新，返回后在系统确认框点「安装」或「更新」。
